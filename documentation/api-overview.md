# API Overview

The backend exposes RESTful API endpoints for the frontend application.

## Authentication

Handles:

- Registration
- Login
- Authentication
- Session management

## Wallet

Handles:

- Balance retrieval
- Wallet funding
- Transaction history

## VTU Services

Handles:

- Airtime
- Data
- Cable TV
- Electricity
- Recharge cards
- Examination pins

## Marketplace

Handles:

- Products
- Cart
- Checkout
- Orders

## Administration

Handles:

- Users
- Transactions
- Products
- System configuration
- Notifications
